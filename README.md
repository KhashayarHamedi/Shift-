# SHIFT prototype

A static responsive product prototype for the Shift innovation ritual.

## Run locally

Open `index.html` directly, or run any static server in this folder.

For example:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Included interactions

* Responsive desktop and mobile navigation
* Animated cinematic home screen
* Working countdown
* Magnetic buttons and card tilt
* Idea reactions
* Mystery mode
* Random Shift generator
* New idea modal
* Command palette with Control K or Command K
* Interactive tech radar
* Full screen live Shift mode
* Live floating reactions
* Reduced motion accessibility support

No backend is required for this prototype.
